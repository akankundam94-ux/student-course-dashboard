
# Student Course Dashboard

## Description
A React application for displaying student courses,
lecturers, progress and completion status.

## Features
- Reusable CourseCard component
- Props
- Array rendering using map()
- Stable keys using course IDs
- Conditional rendering
- Empty state message
- Responsive layout
- Total course count

## Requirements
- Node.js
- npm

## Installation
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run npm install.
4. Run npm run dev.
5. Open the local URL provided in the terminal.
